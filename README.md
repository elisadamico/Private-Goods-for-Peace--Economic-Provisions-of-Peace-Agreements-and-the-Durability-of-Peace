# Private Goods for Peace: Economic Provisions of Peace Agreements and the Durability of Peace

This repository contains replication materials for the paper **"Private Goods for Peace: Economic Provisions of Peace Agreements and the Durability of Peace"**, published in the *Journal of Peace Research*.

## Contents

| File Name           | Description |
|---------------------|-------------|
| `privgoods.csv`    | Dataset used for survival/hazard models assessing peace with Private Goods PCs. |
| `pubgoods.xlsx` | Dataset used for survival/hazard models assessing peace with Public Goods PCs. |
| `DataModels.R`      | R script for preprocessing data and executing statistical models. |

## Usage

Open and run `DataModels.R` in R or RStudio to reproduce the main analyses. Make sure all files are in the working directory.
